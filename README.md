# Engineering Monthly Dashboard (GitHub Pages)

엔지니어링본부 월간 경영 Dashboard 게시본 (조회 전용).

- **게시 URL**: https://ljwk2002-creator.github.io/engineering-dashboard/
- 화면 코드: `index.html` / 데이터: `data.json`

## 월별 갱신 방법
1. 운영 Dashboard(claude.ai)에서 해당 월 Excel Upload
2. Data Management의 **[GitHub 게시용 data.json 저장]** 버튼으로 data.json 다운로드
3. 이 저장소에서 `data.json` 열기 → 연필(Edit)/Upload로 파일 교체 → **Commit**
4. 1~2분 내 게시 URL에 반영 (링크를 가진 모든 사람에게 동일하게 표시)
